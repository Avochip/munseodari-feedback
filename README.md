# 문서다리 피드백

이 저장소는 문서다리의 오류 제보와 기능 제안을 받기 위한 공개 공간입니다.
문서다리의 소스코드는 이 저장소에 포함되어 있지 않습니다.

- 문서다리: https://munseodari.avochip.chatgpt.site/
- 새 피드백 작성: https://github.com/Avochip/munseodari-feedback/issues/new/choose
- 기존 피드백 보기: https://github.com/Avochip/munseodari-feedback/issues

## 피드백 보내기

GitHub 계정으로 로그인한 뒤 **새 피드백 작성**을 눌러 알맞은 서식을 선택해 주세요.

- 작동하지 않거나 결과가 예상과 다르면 **오류 제보**
- 새 기능이나 사용성 개선 의견은 **기능 제안**

비슷한 내용이 이미 등록되어 있다면 새 글을 만들기보다 기존 이슈에 의견이나
반응을 남겨 주세요.

## 공개 게시 전 반드시 확인해 주세요

이 저장소의 이슈, 댓글과 첨부파일은 누구나 볼 수 있고 검색 결과에 나타날 수
있습니다. 다음 정보는 제목, 본문, 댓글과 첨부파일 어디에도 올리지 마세요.

- 실제 업무·고객·학교·회사·기관 문서
- 이름, 전화번호, 이메일, 주소와 계정정보 등 개인정보
- 계약서, 증명서, 진료·금융·인사 정보
- 회사명, 고객명, 프로젝트명 등 기밀정보
- 비밀번호, 인증키, 토큰 또는 악용 가능한 보안 취약점
- 사용자 이름이나 조직명이 포함된 파일명과 저장 경로

화면 이미지를 첨부할 때도 개인정보와 문서 내용이 보이지 않는지 확인해 주세요.

## 샘플 파일 기준

파일 없이 설명할 수 있다면 첨부하지 않는 것이 가장 안전합니다. 파일이 꼭
필요하면 실제 문서를 고쳐서 올리지 말고, 같은 문제가 재현되는 새 더미 문서를
처음부터 만들어 주세요.

첨부할 수 있는 자료:

- 처음부터 허위 이름과 허위 내용으로 만든 더미 문서
- 개인정보와 문서 내용이 보이지 않는 화면 이미지

첨부하면 안 되는 자료:

- 실제 문서에서 이름이나 일부 문장만 가린 파일
- 실제 고객·업무 문서를 복사해 일부만 수정한 파일
- 숨은 정보나 문서 속성이 남아 있을 수 있는 원본 파일

## 접수 후 처리

등록된 의견에는 추가 정보 요청, 중복 안내, 수정·개선 후보 검토 또는 현재 지원이
어려운 이유가 답변될 수 있습니다. 제보가 등록되었다고 해서 수정이나 기능 추가
일정이 확정되는 것은 아닙니다.

## 보안 관련 내용

비밀번호, 인증키, 토큰이나 악용 가능한 보안 취약점은 공개 이슈로 신고하지 마세요.
별도의 비공개 신고 방법이 안내되기 전에는 구체적인 내용을 게시하지 말아 주세요.
